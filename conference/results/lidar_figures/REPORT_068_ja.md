# 068　064の180走行と事前指定の検定の図表

作業ブランチは `codex/068-figures-064`。基点は `realtime-map` の `98ddbde64ff49e21fbacc111c0523ed63ee03e8b`。実装と生成物のコミットは `df67663d39d314ba389b94cdaebfd854737f4774`。この報告は後続コミットに収録する。

## 入力と集計

064の段階1・2を結合した `common_eval_all/runs.csv` の180行を読んだ。GPU描画・1.0倍、6条件それぞれ30走行（5砂浜で各6反復）。このCSVのSHA-256を `sources.json` に追加し、030〜057の入力ハッシュも維持した。 [走行別入力](../eval_064/common_eval_all/runs.csv) · [出典](../../thesis/out_lidar/sources.json)

箱への接近は `min_truth_clearance_m < 0.5`、漂着物マスの通過は `debris_len_m > 0`、完走は `board_outcome == "completed"` とした。T7は走行を単位に、PD対S、GD対S、PD対P、GD対Gの2×2度数表でFisherの両側正確検定を行い、指標ごとに4比較をHolm補正した。欠測した指標を0件として検定に入れない。対象CSVが無い場合はその旨を表示し、F11は記録なし、T7は空欄の表を生成する。 [事前指定](../../tasks/064_eval_2x2.md) · [共通集計の定義](../eval_064/common_eval_all/definitions_ja.md)
