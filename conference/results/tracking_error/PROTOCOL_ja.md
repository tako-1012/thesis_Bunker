# 061 集計前に固定した定義

記録された車体中心のXY標本から、標本時刻以下で最新の受理済み経路の折れ線全体への最短距離を求める。042の `prepare_path` と `nearest_path` を使い、同時刻の経路は最後の版を使う。軌跡の標本時刻を再標本化しない。最初の版より前には対応する経路がない。経路が固定されたことを確認できる旧記録では、保存されたミッションの経路を全標本に対応させる。別購読者が同じ走行を採った follower 記録は重複として数えず、同じ軌跡と経路版のコピーも重ねない。合成記録は実走行の集計に入れない。

| 特徴 | 集計区分 |
|---|---|
| 経路の曲がり | 符号なしMenger曲率が0以上0.02未満、0.02以上0.10未満、0.10以上（1/m）。曲率円の半径50 mと10 mに対応。最近線分の端点のうち射影点に最も近い内点で求める。2点の経路は直線、1点または退化した3点は不明。 |
| 真の地形の傾き | 評価標高格子での既存 `slope_deg` を、標本の最寄りセルで読む。0〜10°未満、10〜20°未満、20〜25°以下、25°超、範囲外・真値なし。 |
| 斜面に対する進み方 | 傾きと交差集計。直前の位置から1 cm以上進み、かつ時刻が増えたときのXY移動方向を用いる。上り方向との角が45°以下なら登り、135°以上なら下り、その間なら横切り。勾配ゼロ、移動不足、最初の標本、真値なしは不明。 |
| 速度の指令 | ゼロ付近は前進指令の絶対値が0.05 m/s以下。0.05超〜0.30未満、0.30〜0.60未満、0.60以上、不明。軌跡の `v` を使い、実速度で補わない。 |
| 経路乗り換え | 最初の経路は独立群。第2版以降は受理記録から0〜2 sim秒未満と2 sim秒以上。計画要求時刻を使わない。経路版が同じ時刻に複数なら最後の版。 |
| 箱までの距離 | 評価用の真値箱への中心XY距離が1.5 m以下、1.5 m超、箱のない世界、不明。コミットされた箱の記録を優先し、保存された評価用世界から幾何を照合して復元できる場合は使う。障害物の格子膨張やセンサー検出は箱の代わりに使わない。 |

全体、各項目と斜度・進み方の交差、実験系列別の分位は標本をプールして求める。50・90・95・99%値はNumPy既定の線形補間、最大・標本数と該当走行数も記録する。停止中や長い走行の標本の影響を数で示し、固定経路と時刻付き版の分布も分けて示す。検定はしない。

0.5 m未満の接近は042と同じ軌跡線分の線形補間と、真値矩形の0.5 m開近傍で連続区間を求める。その区間の最接近点と同じ時刻に有効な経路を使い、同じ箱について経路全体・最近線分・射影点との距離を残す。射影点の距離が厳密に0.5 m未満なら「経路が近すぎた」、0.5 m以上なら「追従のずれ」とラベル付けする。これは最接近時の幾何による分類。既存の接近証拠表に必要な値だけが保存されている場合も、出所を明示して同じ分類を適用する。走行別集計に区間数しかないものは未判定として別に示す。

`R_hard + q95` は既存の0.5 mにずれの分位を足した参考値。計画された経路上の同じ参照点にその距離が確保された場合の幾何的な目安で、ソフトコストの到達距離を安全保証に読み替えない。
