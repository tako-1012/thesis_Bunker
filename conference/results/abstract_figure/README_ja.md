# ICAROB アブストラクト用の図：本物の砂浜で A* と TA*-S の経路を重ねた図

作り方：`python3 -m experiments.abstract_figure`（`conference/` から）。既存の結果・図は変えていない。

## データと設定
- 点群の砂浜（`shizuoka_beach_las`）の `test`、200m、シード 0、漂着物なし。指示書013（`results/real_beach_las/`）と同じシナリオ・同じスタートとゴール。
- A* と TA*-S exact（w=8、α=0.5）を計算し直した。経路長・平均地形コスト・登った高さ・急斜面を通った距離・J は、`results/real_beach_las/offline.csv` の値と一致した（`abstract_figure_log.txt` の「offline.csv match」）。
- 図は印刷する大きさ（1.8 インチ＝約 4.6cm 四方）で作り、文字は 8pt。PNG は 300dpi、PDF も同じ図。

## 砂浜の選び方（図を作る前に決めた規則）
- **規則 1（依頼の規則）**：test の一覧の順で、A* の経路が急斜面（25° 超）を通る最初のシナリオ → **`08OB86_-0205`**。
  ただし、A* が急斜面を通る距離は 0.5m だけで、4.5cm の図では見えない。違いは主に「A* が凸凹の多い陸側の縁を通り、TA*-S は平らな所を回る」こと。
- **規則 2（参考）**：test の中で、A* の経路が急斜面を通る距離が最も長いシナリオ → **`08OB88_-0167`**（43.5m）。
  「最も極端な例」なので、使う場合は図の説明にそう書くこと（都合のよい例を選んだのではなく、最大の例と明記する）。
- test 48 か所のうち、A* が急斜面を通るのは 9 か所（各砂浜の値は log にある）。

## 色
グレー：傾斜（濃いほど急）、赤：25° を超える所、薄い青：海、薄い紫：データのない所。A* は青の破線、TA*-S は橙の実線（Okabe–Ito の色、色覚に配慮）。
S：スタート、G：ゴール、左下に 20m の目盛り。

## 注意
- `08OB88_-0167` では、TA*-S の経路は A* の約 1.8 倍の長さになる（急斜面を避けて大きく回るため）。
- この砂浜（200m）は、指示書019 の Gazebo で TA*-S も転倒した場所（経路から 0.3〜0.8m ずれて急斜面にかかった）。指示書020 の急斜面の膨らませを入れると「経路なし」になる。
  本文で使う場合は、この点に触れられる可能性がある。
- エネルギーの値は出していない。

## 拡大版（規則 1、`astar_vs_tas_rule_first_08OB86_-0205_zoom.png`／`.pdf`）
作り方：`python3 -m experiments.abstract_figure --zoom`。砂浜と経路は規則 1 の図と同じ（`offline.csv` と一致）。元の図のファイルは変えていない。
- 2 本の経路は、横 約 149m・縦 約 21m の細長い範囲に入る。外接する四角に 10m の余白を付けて 1:1 にすると約 169m 四方になり、元の図（約 165m 四方）より大きくならない。
- そのため、1.8 インチ四方の中を 2 段に分けた：
  - 上：経路全体（外接する四角＋10m）を帯として描き、S・G と 20m の目盛りを付ける。黒い枠が下の拡大の範囲。
  - 下：経路が分かれ、25° を超える所がある範囲（x 55〜125m、y 99〜149m）を拡大。10m の目盛りを付ける。
- 拡大の範囲は、経路の近くの急斜面のマスがある x 60〜120m を含むように、地形と経路の形だけで決めた（結果の値は見ていない）。
- 色・線・凡例・文字の大きさ（8pt）・300dpi は元の図と同じ。log は `abstract_figure_zoom_log.txt`。
