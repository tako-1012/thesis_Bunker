# 070 追従のずれを通行不可の余白に加える

**保存地図14件で、経路が見つかった件数は `prior` で10件から6件、`sensor` で1件から0件に減った。** `fixed` と `slope` はこの14件では同じ結果になった。両条件で失われた5経路は、目標が計画地図の急斜面から0.5 m未満になり、追加帯の緩和の対象外だった。合成地図では、始点と目標を通行可のままにしても、格子上の幅1.5 mの通路が両条件で塞がった。 [走行別CSV](runs.csv) · [合成通路](narrow.csv)

作業ブランチは `codex/070-tracking-margin`。作業開始時の `realtime-map` は `9eee50fed7e2104fc189531d7d6f1db4cb832a7b`。実装・テスト・再計算結果は `129bf2da2153de965dffbb4008cb25f1966a8b9f`。本報告は後続コミットに収録した。

## 限界

0.774 m・1.114 mの判定は計画セルの中心に対するもので、実軌跡や連続経路の最短距離を保証しない。計画層が未検出の障害物や誤推定した斜面もある。端点の緩和は同じ距離層の帯にその計画全体で作用するので、端点以外で余白が狭まることもある。061の95%値は保存走行の分布で、実際の追従誤差の上限ではない。14件の終了時地図では狭い通路の効果を一般化できず、走行途中の地図変化・追加処理の実時間負荷も未評価。Gazeboと研究PCは使用していない。

<summary>距離の追加照合に使用した一時スクリプト</summary>

~~~~python
import csv
from pathlib import Path

from results.distance_clearance import replay as boxes
from results.false_steep_causes import replay as causes
from results.steep_clearance import replay as slopes
from tapp.pointcloud_map_fine import PointCloudMapFine
from tapp.traversability import slope_deg

source = Path('results/tracking_margin/runs.csv')
with source.open() as stream:
    rows = list(csv.DictReader(stream))
paired = {(r['archive'], r['terrain'], r['tracking_margin']): r for r in rows}
tracked = causes.committed_inputs(causes.ROOT)
records = {str(raw): row for raw, row, _ in causes.discover(causes.ROOT, tracked) if row}
for (raw, terrain, mode), original in paired.items():
    if mode != 'none' or original['route'] != 'True':
        continue
    fixed = paired[raw, terrain, 'fixed']
    if fixed['route'] == 'True':
        for key in ('path_m', 'min_box_m', 'min_steep_m', 'box_below_05_m',
                    'box_below_0774_m', 'steep_below_05_m', 'steep_below_0774_m'):
            assert original[key] == fixed[key] == paired[raw, terrain, 'slope'][key]
        continue
    record = records[raw]
    _, _, _, _, _, _, _, base, final, _ = causes.read_record(causes.ROOT, tracked, Path(raw), record)
    mapper = PointCloudMapFine(base.prior, base.raw_obstacle, terrain_source=terrain,
                               obstacle_clearance='distance', steep_clearance='distance')
    if terrain == 'sensor':
        slopes.install_steep(mapper, slope_deg(final['elev']) > mapper.robot.max_slope_deg)
    boxes.install_mask(mapper, final['fine_obstacle'])
    goal = tuple(int(record[f'goal_{axis}']) for axis in 'xy')
    distance = mapper.steep_distance_field.distance_m[goal]
    assert distance < .5 and not mapper.lethal[goal] and fixed['goal_blocked'] == 'True'
    print(f"{original['patch']} {terrain} {original['condition']}_r{original['rep']} {goal} steep={distance:.12f} m")
~~~~
