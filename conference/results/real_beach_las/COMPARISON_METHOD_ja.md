# タスク013の固定した比較方法

実験A〜Dは指示書009と同じ計算・重み・閾値・シードで実行する。比較のためにプランナーを調整しない。
CSVの行順ではなく、パッチ名・大きさ・シード・漂着物と各方式のキーで1対1対応を検査する。
欠落キー・重複キーは例外とし、同名のケースを無言で落とさない。成功／失敗は別に記録する。
各データの中央値・裾はそのデータで成功したケースから、データ間の対応差は両方で成功したケースから計算し、件数を分けて表示する。

- A：全60パッチの中央値、対応する新−旧差の中央値。人工地形の中央値が実測のp10〜p90の範囲外かを旧／新それぞれで判定する。
- Bの元の検定群：指示書009の5指標（急斜面長、平均地形コスト、登り、A*比エネルギー、経路長）×漂着物2条件＝10検定をそのまま再現する。
- Bの依頼された指標群：急斜面を通った経路の割合、平均地形コスト、登り、A*比エネルギー、経路長、横傾き95%値×2条件＝12検定を別の補足群で実施する。
  元の10検定に指標を足して補正群を変え、元の結論が変わったと扱うことはしない。両群とも旧／新で同じ両側Wilcoxon＋Holmを用い、有意水準は0.05。
  向きは対応のある順位二分相関rの符号を使用する。中央値差が0でも、ゼロ差でないペアに一方向の差がある場合を区別する。
  非有意な向きの変化は記述的なものとして、有意性の変化と分けて表示する。
- C：漂着物・大きさ・方式ごとのdJ中央値、p90（悪い側10%）、最大、対応差の中央値。
  全方式の接触数を表示し、実際の再計画5方式の安全性をまとめる際は比較用oracleを除外する。
- D：地点数・漂着物ごとに `100*(terrain dir / euclid - 1)` の物理コスト・エネルギーの中央値とp90、対応差の中央値。
  負ならterrain dirが小さい。元の検定表も対比較する。
  旧報告との直接照合用に、元のCSV列から `100*(euclid / terrain dir - 1)`（euclidの過剰率）の中央値・p90も並記する。
  分母と符号の異なる記述表示であり、プランナー・シナリオ・元の検定群は変えない。

同じ生成シードでも地形マスクが異なれば、リトライ・開始終了点・サンプルされた巡回地点は変わり得る。
これは指示された同じ名目シナリオの再実行であり、すべての座標を固定した因果比較ではない。種・切り出しと巡回点の対応も監査する。
時間は実測値を保存するが、旧／新の実行機・負荷・ワーカー数が異なるため処理速度の改善とは解釈しない。
