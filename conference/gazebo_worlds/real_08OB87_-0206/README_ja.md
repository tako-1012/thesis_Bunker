# Gazebo Harmonic用の地形

元地図：`real_08OB87_-0206_200m_0.npz`。静岡県「VIRTUAL SHIZUOKA 静岡県 中西部沿岸 点群データ」ALB グリッドデータ（0.5m）。https://www.geospatial.jp/ckan/dataset/shizuoka-2025-pointcloud-alb 。CC BY 4.0 / ODbL。この地図は、上のデータを加工して作成したものです。

Ubuntu 24.04でGazebo Harmonicをインストール後、このフォルダで実行します。

```bash
export GZ_SIM_RESOURCE_PATH="$PWD:${GZ_SIM_RESOURCE_PATH:-}"
gz sim world.sdf
```

高さ画像は2049×2049画素、16 bitグレースケールです。
元格子中心に戻す最大誤差が0.1m以下となる最小の2^n+1画像を選びます。
地図の各マス中心は(x,y)=(i×0.5,j×0.5)m、x右向き・y上向き、PNGの上端は+y側です。
地形の範囲は両軸とも−0.25〜199.75m、原点は最初のマス中心です。
マス境界まで半マス延長して双線形補間し、端は最近傍値で延長しました。
NaNは地図ローダーで最近傍の実測値を使って埋めます。高さは最小値-1.2999999523162842mをpos.zに、幅8.0999524593353271mをsize.zに分けています。
16bit量子化の上限は6.1798675969598893e-05m、元格子中心へ戻した最大誤差は0.063742008853256316mでした。
障害物は膨張前マスクの4近傍連結成分ごとの軸平行な外接箱0個です。
各箱はその領域の最小標高より0.1m下から最大標高より0.5m上までとする形状の仮定です。穴や非矩形部分も箱で覆います。
摩擦係数は仮定値1.0（測定値ではありません）。水面はz=0の見た目だけの平面で、衝突を作りません。
通行不可の傾斜・水・データなし・安全余白はPython側の計画マスクであり、Gazeboの箱と同じものではありません。
この環境ではGazeboを実行していません。XML・PNG・標高の復元だけを検証しました。
